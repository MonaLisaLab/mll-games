# mll-games

ブラウザで遊べるゲームを置くリポジトリです。

## スネークゲーム DX（index.html）

りんごを食べてヘビを伸ばすスネークゲーム。単一HTMLファイルで動作します。

- 操作：画面をなぞった方向にヘビが自由に動く（斜め・カーブOK）。PCはマウスドラッグ
- 壁はすり抜けて反対側から出現。ゲームオーバーは自分の体と岩（障害物）に当たったときだけ
- コンボ＆フィーバー（全得点2倍）、レベル制、3モード（クラシック／ラップ／カオス）
- アイテム（スター／シールド／スロー）、ミッション20種、全10ステージ制
- スキン解放、ゲームオーバー時のS〜SSランク評価、効果音つき
